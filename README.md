# Klassenverteilungsoptimierer V5

Excel-Makro (VBA) zur optimierten Verteilung von Schülern auf Klassen.

## Enthaltene Dateien

| Datei | Beschreibung |
|---|---|
| `Klassenverteilungsoptimierer_V5.xlsm` | Excel-Datei mit allen Makros |
| `Modul2.bas` | VBA-Quellcode (importierbar) |
| `Gebrauchsanleitung_Klassenverteilungsoptimierer_V2.docx` | Vollständige Dokumentation |
| `Kurzanleitung_Klassenverteilungsoptimierer_V2.docx` | Kurzreferenz für den täglichen Einsatz |

## Voraussetzungen

- Microsoft Excel mit aktivierten Makros
- Makrosicherheit: Makros müssen zugelassen sein

## Schnellstart

1. `Klassenverteilungsoptimierer_V2.xlsm` öffnen und Makros aktivieren
2. Schülerdaten im Blatt **alle** eintragen
3. Parameter im Blatt **Suchtiefe** konfigurieren
4. Makro `Klassen_Optimierer` starten
